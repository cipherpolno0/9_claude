# แผนเปิดใช้: นำร่อง 1 จังหวัด แล้วขยาย

จังหวัดนำร่อง: **[ชื่อจังหวัด]** (นิกาย: [ ]) — ผู้สั่งงานกำหนดภายหลัง
ระยะเวลานำร่อง: 2 สัปดาห์ เริ่มวันที่ [ ] ถึงวันที่ [ ]

## 1. เป้าหมาย

- ผู้ใช้จริงในจังหวัดนำร่องทำงานหลักครบทุกระบบที่เกี่ยวข้อง โดยไม่ต้องใช้กระดาษคู่ขนาน (ยกเว้นเอกสารที่ระเบียบกำหนดให้ลงนามจริง)
- รวบรวมข้อเสนอแนะ ข้อผิดพลาด และจุดที่ใช้ยาก เพื่อแก้ก่อนขยาย
- ยืนยันว่าการนำเข้าข้อมูล การสำรองข้อมูล และการติดตามระบบ ใช้ได้กับข้อมูลจริง

## 2. ผู้เข้าร่วม

| กลุ่ม | บทบาทในระบบ | คู่มือ |
|---|---|---|
| เจ้าคณะจังหวัด อำเภอ ตำบล และรองเจ้าคณะ ในจังหวัดนำร่อง | เจ้าคณะ / รองเจ้าคณะ | คู่มือผู้ใช้: เจ้าคณะ |
| เลขานุการเจ้าคณะทุกชั้นในจังหวัด | เลขานุการ | คู่มือผู้ใช้: เลขานุการ |
| เจ้าหน้าที่สำนักเรียนในจังหวัด | เจ้าหน้าที่สำนักเรียน | คู่มือผู้ใช้: เจ้าหน้าที่สำนักเรียน |
| เจ้าหน้าที่ส่วนกลางที่เกี่ยวข้อง และผู้ดูแลระบบ | เจ้าหน้าที่ส่วนกลาง / ผู้ดูแลระบบ | คู่มือผู้ใช้: ผู้ดูแลระบบ |

คู่มือทั้ง 4 เล่มอยู่ที่หน้า ดาวน์โหลด > คู่มือ

| สิ้นสุดนำร่อง | สรุปผลตามตัวชี้วัดข้อ 5 และตัดสินใจขยาย | ผู้สั่งงาน |

## 4. การเก็บข้อเสนอแนะ

- ช่องทางหลัก: หน้า **ติดต่อเรา** หัวข้อ **ข้อเสนอแนะการนำร่อง** (เข้ากล่องข้อความของผู้ดูแลระบบ ตั้งผู้รับเพิ่มได้ที่ ผู้ดูแลระบบ > ติดต่อเรา)
- ขอให้ระบุ: หน้าเว็บที่ใช้ งานที่ทำ สิ่งที่เกิดขึ้น สิ่งที่คาดหวัง และรหัสอ้างอิงถ้าหน้าจอแสดง
- ผู้ดูแลระบบจัดสถานะข้อความ ใหม่ > กำลังดำเนินการ > เสร็จแล้ว และจัดกลุ่มเป็น ข้อผิดพลาด / ใช้ยาก / ขอความสามารถเพิ่ม / ข้อมูลผิด
- ข้อเสนอที่ต้องแก้โค้ดรวบรวมเป็นรายการให้ผู้สั่งงานจัดลำดับ แก้บนชุดทดสอบก่อนเสมอ

## 5. ตัวชี้วัดและเกณฑ์ขยาย

| ตัวชี้วัด | วิธีวัด | เกณฑ์ขยาย |
|---|---|---|
| ผู้ใช้เข้าสู่ระบบได้ | บัญชีที่ใช้งาน / บัญชีที่สร้าง (ผู้ดูแลระบบ > บัญชีผู้ใช้) | อย่างน้อยร้อยละ 80 |
| ปัญหาร้ายแรงค้าง (ข้อมูลผิด สูญหาย เห็นข้อมูลข้ามเขต ระบบใช้ไม่ได้) | ข้อเสนอแนะกลุ่ม ข้อผิดพลาด ที่ยังไม่เสร็จ | 0 รายการ |
| ข้อผิดพลาดของระบบ | หน้า สถานะระบบ 7 วันล่าสุด | ไม่มีข้อผิดพลาดที่เกิดซ้ำโดยยังไม่ทราบสาเหตุ |
| งานหลักทำได้จบในระบบ | คำขอ หนังสือ บัญชีสมัครสอบ ที่ทำครบขั้นตอน | ทุกชนิดงานที่เกิดในช่วงนำร่องทำจบได้อย่างน้อย 1 รายการ |
| การสำรองข้อมูล | GitHub Actions | สำเร็จครบทุกวัน และซ้อมกู้คืนผ่าน 1 ครั้ง |
| ความพึงพอใจ | แบบสอบถามสั้น 5 ข้อท้ายนำร่อง | เฉลี่ยไม่ต่ำกว่า 3.5 จาก 5 |

ไม่ผ่านเกณฑ์ข้อใด: ขยายเวลานำร่องจังหวัดเดิมอีก 1 สัปดาห์หลังแก้ไข แล้ววัดใหม่

## 6. การขยาย

1. ขยายทีละภาค (หรือทีละกลุ่มจังหวัด) ภาคละ 1 สัปดาห์ เริ่มจากภาคของจังหวัดนำร่อง
2. แต่ละภาค: นำเข้าข้อมูล > อบรม > ใช้งาน > เก็บข้อเสนอแนะต่อเนื่องด้วยช่องทางเดิม
3. ก่อนขยายแต่ละรอบ ตรวจโควตาฐานข้อมูลและที่เก็บไฟล์ของแผน Supabase (แผนฟรีมีขีดจำกัดขนาดและโครงการที่ไม่มีการใช้งาน 7 วันจะถูกหยุดชั่วคราว ควรอัปเกรดเป็นแผน Pro ก่อนเปิดใช้ทั้งประเทศ)
4. เมื่อครบทุกภาค ปิดหัวข้อติดต่อ ข้อเสนอแนะการนำร่อง โดยตั้งผู้รับเป็นผู้ดูแลระบบตามปกติ (หัวข้อยังคงอยู่ไว้เป็นประวัติ)
